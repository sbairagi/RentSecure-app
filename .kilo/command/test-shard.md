# test-shard

Run jest shard with coverage.

## Configuration

```jsonc
{
  "command": {
    "test-shard": {
      "template": "Run test shard {shard}",
      "description": "Run jest shard with coverage",
      "agent": "build",
    },
  },
}
```

## Usage

Invoke the `test-shard` command in a Kilo session.
