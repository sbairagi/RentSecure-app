# AI Developer Onboarding Guidance

Context and guidance for AI developers working in this repository.

## Project Context

This is a React Native Expo Router mobile application for the RentSecure platform.

## Getting Started

- Use `npm start` to run the Expo dev server.
- Use `npm run lint` to run linting.
- Use `npx tsc --noEmit` to run TypeScript checks.
- Use `npx jest` to run tests.

## Important Conventions

- Follow the architecture and mobile rules in this instruction library.
- Do not modify native iOS/Android projects directly unless necessary.
- Keep changes minimal and focused on the task at hand.
- Validate changes with CI before requesting review.
